One original fortune-cookie line for a software developer, written by a
deterministic program for the make.fun competition "Fortune Cookie Wisdom
for Developers".

## The line

> The intern will fix in an afternoon the bug you have owned for a year, and smile while doing it.

## Layout

- `main.ts` — the entrypoint: writes the single line (96 characters) to
  `/output/entry.txt`. Node 22, stdlib only, deterministic, no network.

## Run it

```sh
node main.ts
```
